# Related work and positioning

Reviewed on 2026-09-29. These are references, not dependencies. Descriptions reflect the cited public material; we have not run head-to-head benchmarks against these repositories.

Dialectic packages stable issue identity, critique adjudication, evidence-scoped closure, minimal revisions and explicit handoffs into one instruction-only workflow. These ideas are not claimed to be new, exclusive, or universally superior.

A more capable framework is not automatically a better fit for a lightweight Skill; a smaller Skill is not automatically cheaper or more accurate. Both require measurement.

Use the project if its review contract fits your workflow. If an existing tool already solves your task, using or contributing to it may be the better choice. Keep attribution if reusing others' code or text; the project instructions here were authored for this release, not copied from the linked repositories.
