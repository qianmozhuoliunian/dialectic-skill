# 学习计划：一个月做出小型 AI 项目

类型：人为编写的教学示例，非对任何真实用户掌握程度的认定。

## 输入

> 我有 Python 基础，看过 FastAPI 入门。每天能学四小时。
> 想一个月做出能演示的 AI 项目，但打算同时学 Java、三个 Agent 框架、
> RAG、Docker 和所有常见算法。请帮我反驳并优化。

## 确定目标

B1：一个月、每天四小时；目标是独立演示并解释一个小项目。保留项目主线和持续算法练习。看过教程不等于能独立实现，当前能力需要小任务确认。

## 一轮问题记录

| ID | 问题与边界 | 裁决与验收 |
| --- | --- | --- |
| C1 | 多条学习主线竞争同一时间预算；若已有熟练基础，部分复习可能很短，但当前没有证据 | 接受，先只保留直接服务项目的内容；每天安排总计四小时 |
| C2 | 计划默认已经能独立写 API，但输入只说明看过入门教程 | 接受，needs-evidence；通过一个小任务核验，不要求先重学整门课程 |
| C3 | 一个月必须掌握所有常见算法 | rejected。与本次可演示项目目标不匹配；保留少量持续练习即可 |

## 修改后的安排

今天四小时：
- 30 分钟：明确一个最小需求——接收问题并返回一个可预测的测试回答。
- 90 分钟：独立编写一个本地接口，允许查官方文档；卡住时记录具体报错。
- 60 分钟：用请求验证正常输入和空输入，解释请求如何进入函数并返回结果。
- 40 分钟：独立做一道数组或哈希表基础题，先写思路再编码。
- 20 分钟：记录完成项、失败项和明天最小任务。

先不排满一个月的所有技术细节。接口小任务通过后，再加真实模型调用；没有通过，就缩小为普通 Python 函数并补对应缺口。
